# GitHub repo metadata recommendations

These are the public signals that don't live in code — repo description,
website link, and topic tags. Only a repo owner/admin can change them, so
this file is the canonical source of what they should be set to.

`citylens-core` currently undersells itself on the GitHub repo page (no
description, no website, no topics). The library is the algorithm layer
behind a real product (https://www.citylens.dev) and should look that way
to anyone landing on the repo.

## Recommended GitHub settings for `citylens-core`

| Field | Value |
|---|---|
| Description | Reusable Python pipeline for urban change detection and 3D reconstruction from aerial imagery. Powers https://www.citylens.dev. |
| Website | https://www.citylens.dev |
| Topics (comma-separated) | `python`, `geospatial`, `change-detection`, `3d-reconstruction`, `segmentation`, `sam2`, `lidar`, `gis`, `mesh-generation`, `aerial-imagery` |

## How to update

1. Go to https://github.com/joshvern/citylens-core
2. Click the ⚙️ icon next to the "About" panel on the right sidebar
3. Paste the description, website, and topics from above
4. Save

This file should be kept in sync if the live product URL or positioning changes.
